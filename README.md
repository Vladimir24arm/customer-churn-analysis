# Анализ оттока клиентов телеком-компании (Telco Customer Churn)

## О проекте
Проанализировал 7043 клиента телеком-компании. Цель - выявить причины оттока и предложить рекомендации по удержанию.

## Данные
- Источник: Kaggle (Telco Customer Churn).
- Объем: 7 043 клиента, 21 колонка.
- Целевая переменная: `Churn` (Yes/No).

## Инструменты
- Python (Pandas, Matplotlib)
- Jupyter Notebook

## Ключевые выводы
1. **Общий отток:** 26.54% клиентов уходят.
2. **Тип контракта:** клиенты с помесячной оплатой уходят в 15 раз чаще, чем с двухлетним контрактом (42.71% против 2.83%).
3. **Техподдержка:** клиенты без техподдержки уходят в 2.7 раза чаще (41.64% против 15.17%).
4. **Стаж:** новые клиенты (до 12 месяцев) уходят в 3.4 раза чаще, чем лояльные (47.44% против 14.04%).
5. **Способ оплаты:** клиенты с электронным чеком уходят в 3 раза чаще, чем с картой (45.29% против 15.24%).
